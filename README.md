# Компас Тревел — калькулятор стоимости тура

Прототип калькулятора для туристического агентства «Компас Тревел».
Менеджер выбирает направление, указывает количество дней и число туристов — стоимость
появляется сразу.

**Живая версия:** https://tugarin9999.github.io/compass-travel/
**Репозиторий:** https://github.com/Tugarin9999/compass-travel

## Зачем он нужен

Агентство принимает заявки по телефону и в мессенджере, и менеджер прикидывает цену
поездки по памяти и старым прайсам поставщиков. Расчёт получается долгим и нередко
расходится с реальной ценой: часть расходов забывают учесть.

Калькулятор считает все составляющие поездки и показывает, из чего сложилась сумма.
Менеджер видит расходы построчно и может сравнить их со своим расчётом.

## Как открыть

Откройте `index.html` в браузере — двойным щелчком, без сервера и без интернета.

Сборки нет, зависимостей нет. Внешние библиотеки и шрифты не подключаются, поэтому
калькулятор полностью работает офлайн и открывается прямо с диска.

## Как считается стоимость

Сумма складывается из отдельных статей расходов. У каждой статьи есть вид, который
определяет, как она умножается:

| Вид статьи | Формула | Пример |
| --- | --- | --- |
| `perPersonPerNight` | цена × ночи × туристы | проживание и питание |
| `perPersonPerDay` | цена × дни × туристы | медицинская страховка |
| `perPersonOnce` | цена × туристы | экскурсия |
| `perGroupOnce` | цена | трансфер на всю группу |

Калькулятор показывает итог, цену на одного туриста и разбивку по статьям.

Пример: Турция, 7 дней, 2 туриста — **83 100 ₽**, из них проживание 75 600 ₽,
страховка 4 900 ₽, трансфер 2 600 ₽. На одного туриста — 41 550 ₽.

Валидация: от 1 до 365 дней и от 1 до 60 туристов. Ноль, пустое поле или число вне
диапазона дают понятное сообщение вместо молчаливого нуля в результате.

## Как поменять цены

Все цены и направления лежат в `prices.js`. Расчётный код их не трогает — правьте
только этот файл, новый код писать не нужно.

```js
{
  id: 'turtsiya',
  name: 'Турция',
  note: 'Анталья, отель 4*, всё включено',
  positions: [
    { label: 'Размещение и питание', kind: 'perPersonPerNight', price: 5400 },
    { label: 'Медицинская страховка', kind: 'perPersonPerDay', price: 350 },
    { label: 'Трансфер аэроппорт — отель', kind: 'perGroupOnce', price: 2600 }
  ]
}
```

- `id` — технический идентификатор направления, латиницей;
- `note` — подпись, которая показывается в выпадающем списке;
- `label` — название статьи в разбивке;
- `kind` — один из четырёх видов из таблицы выше;
- `price` — цена в рублях.

Чтобы добавить направление, скопируйте существующий блок и поменяйте значения.
Список в выпадающем списке собирается из этого файла автоматически: разметку
править не нужно.

## Важно: цены в репозитории — образец

Числа в `prices.js` взяты для примера и **не являются действующим прайсом поставщика**.
Перед использованием подставьте реальные цены агентства.

## Что пока не входит

Прототип закрывает одну задачу — быстрый предварительный расчёт. Бронирования,
оплаты, личных кабинетов и интеграции с API поставщиков здесь нет намеренно.

Расчёт предварительный: он показывает ориентир для первого разговора с клиентом.
Точную стоимость подтверждает менеджер.

## Файлы

- `index.html` — разметка, форма ввода и блок вывода;
- `styles.css` — оформление;
- `prices.js` — прайс: направления, цены и статьи расходов;
- `app.js` — расчёт, валидация и вывод.

## Как проверить изменения

Откройте `index.html` в браузере и поменяйте значения в полях — пересчёт происходит
сразу, кнопки «рассчитать» нет.

Автотестов в проекте нет, и это осознанное решение: калькулятор настолько мал, что
быстрее проверить его руками. Правила работы с репозиторием описаны в `AGENTS.md`.
