# AGENTS.md

## Что это за репозиторий

Прототип калькулятора стоимости тура для туристического агентства «Компас Тревел».
Боль клиента: менеджер вручную прикидывает цену поездки по памяти и старым прайсам
поставщиков — расчёт долгий и расходится с реальной ценой.

ТЗ лежит в `задание.txt` — единственный источник требований. Читай его перед
изменениями продукта.

## Стек: статика без сборки

HTML + CSS + обычный JS. Без зависимостей, без npm, без бандлера, без тестового
раннера. Отсюда следуют правила, которые нельзя угадать по коду:

- **Не ищи команды `dev` / `build` / `lint` / `typecheck` — их нет и не будет.**
  Сборки нет: правку файла видно после перезагрузки страницы в браузере.
- Проверка изменений — открыть `index.html` в браузере. Автотестов нет; не добавляй
  раннер «про запас» под предлогом «а вдруг понадобится».
- Если нужно проверить расчёт без ручного открытия браузера: `chrome
  --headless=new --disable-gpu --virtual-time-budget=3000 --dump-dom <file://-урл>`
  печатает DOM уже после выполнения скриптов. Скалярные проверки удобно делать
  копией страницы во временной папке с добавленным инлайн-скриптом, который
  задаёт значения полей и шлёт событие `input`. Учти: `Intl.NumberFormat`
  разделяет разряды неразрывным пробелом, который в дампе выглядит как
  `&nbsp;`, — искомое «83 100 ₽» в сыром дампе не найдётся.
- Node в окружении может отсутствовать, поэтому не рассчитывай на `node --check`
  для проверки синтаксиса.
- **Страница обязана работать, открытая с диска (`file://`).** Поэтому прайс лежит
  в отдельном `.js`-файле, подключаемом через `<script src>`, а не в `.json` с
  `fetch()`: запрос локального JSON по `file://` падает из-за CORS. Если всё же
  понадобился сервер — `python -m http.server 8000` из папки проекта.
- Не подключай CDN-библиотеки и внешние шрифты: прототип должен открываться без
  интернета.

## Ожидаемая раскладка файлов

- `index.html` — разметка, форма ввода, место для вывода цены
- `styles.css` — оформление
- `prices.js` — прайс: цена за ночь по направлениям и допы
- `app.js` — расчёт и вывод

## Прайс

Цены лежат в репозитории, в одном месте, и правятся менеджером без изменения кода
расчёта. Держи `prices.js` чистой таблицей данных: не смешивай константы прайса
с расчётной логикой из `app.js`. Деньги — в рублях, округление до целых.

## Требования MVP

Обязательный минимум — три ввода: направление, количество дней, число туристов.
На выходе — примерная стоимость поездки, показанная сразу, без дополнительных шагов,
без кнопки «рассчитать». Ноль дней или ноль туристов — не молчаливый ноль в
результате, а понятное сообщение.

## Что НЕ делать

- Не добавлять продуктовый скоуп: бронирование, оплату, личные кабинеты, админку,
  реальный API поставщиков. ТЗ прямо просит рабочий прототип, а не продукт.
- Не вкладываться в продакшен-дизайн. ТЗ: важна работоспособность и попадание
  в суть запроса.
- Не переписывать `задание.txt` — правь код, а не ТЗ.

## Обязательная часть результата

По ТЗ результат нужно опубликовать (сайт, GitHub/GitVerse или другой доступный
сервис) и отправить через форму отправки результата. Это часть задачи, а не
дополнительная опция: работающий код, который запускается только локально, ТЗ
не закрывает.

## Конвенции

Всё на русском: интерфейс, комментарии в коде, документация, тексты сообщений.
Это русскоязычное агентство, и пожелание клиента сформулировано по-русски.

## Особенности окружения

Имя папки и имя файла ТЗ содержат кириллицу. В командах и скриптах путь
`задание.txt` нужно брать в кавычки, иначе PowerShell и часть CLI его не найдут.

Git инициализирован, но коммитов ещё нет, ветка `master`, remote не настроен —
репозиторий никуда не опубликован. Публикация по ТЗ не сделана, поэтому
при следующем шаге сначала нужен коммит, потом remote.
